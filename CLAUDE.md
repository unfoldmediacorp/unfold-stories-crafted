# Unfold Media Corp Website

This repository contains the official website for Unfold Media Corp.
It is built with React, TypeScript and Vite.
The project is primarily edited in Loveable, while Claude Code is used for architecture, debugging and code improvements.

## Development Rules

- Always run `git pull` before making any changes.
- Never make design decisions unless explicitly instructed.
- Verify every change with:
  - `bun run lint`
  - `bun run build`
- Fix any build, lint or type errors before committing.
- Commit only logical units of work.
- Push to GitHub after verification.
- If a Loveable change introduces issues, fix them without altering the intended design.
- Never refactor working code unless requested.
- Preserve the existing visual design unless the task explicitly involves design changes.

## Claude Code vs Loveable — division of work

Handle **directly in code** (do not ask Loveable to regenerate the page):

- Colours
- Spacing
- Typography
- Responsiveness
- Animations
- Accessibility
- SEO
- Performance
- Minor UI refinements

Use **Loveable** only for:

- Major layout changes
- New sections
- Significant visual redesigns

## Notes

- Package manager is **bun** (`bun.lock`). Do not use npm or yarn — a
  `package-lock.json` would diverge from the lockfile Loveable builds against.
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin during
  build. It is committed, but never hand-edit it.
- `AGENTS.md` is managed by Loveable (`LOVABLE:BEGIN`/`LOVABLE:END` markers).
  Do not edit inside those markers.
- Never force-push, rebase, amend or squash already-pushed commits — it
  rewrites history on Loveable's side and can lose project history.
